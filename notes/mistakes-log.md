\# Mistakes Log



\## Error 001



Tema:

ARP



Error:

Pensar que el gateway responde con la MAC del host local.



Corrección:

El host propietario de la IP responde.



\---



\## Error 002



Tema:

IP Destino vs MAC Destino



Error:

Creer que la IP destino cambia al gateway.



Corrección:

La IP destino siempre permanece siendo el destino final.



\---



\## Error 003



Tema:

Network ID



Error:

Confundir la IP del host con la red.



Corrección:

La red identifica el segmento.

La IP identifica el dispositivo.



\---



\## Error 004



Tema:

Routing



Error:

ARP al host remoto.



Corrección:

Si la red es remota:

ARP al gateway.
