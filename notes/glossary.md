\# Glossary



ARP

Address Resolution Protocol



ARP Cache

Tabla IP ↔ MAC utilizada por el host.



MAC Table

Tabla MAC ↔ Puerto utilizada por el switch.



Broadcast

Trama dirigida a todos los dispositivos.



Unicast

Trama dirigida a un único dispositivo.



Network ID

Identificador de la red.



Host ID

Identificador del dispositivo dentro de la red.



Connected Route

Ruta conectada directamente a una interfaz.



Default Route

Ruta utilizada cuando no existe una ruta específica.



Longest Prefix Match

Regla utilizada por el router para seleccionar la ruta más específica.
