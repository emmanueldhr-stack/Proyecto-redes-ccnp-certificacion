\# Ethernet Fundamentals



\## WHY



Permitir la comunicación dentro de una red local.



\## WHAT



Ethernet utiliza direcciones MAC para identificar dispositivos.



\## Conceptos



\- MAC Address

\- Broadcast

\- Unicast

\- Ethernet Frame



\## Regla Fundamental



Un switch toma decisiones utilizando la MAC destino.



\## Lessons Learned



Una dirección MAC identifica una interfaz dentro de una LAN.
