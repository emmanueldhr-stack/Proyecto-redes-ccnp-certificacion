\# Packet Walk Remote



\## Escenario



PC-A -> Router -> Red Remota



\## Flujo



1\. PC-A calcula su Network ID.



2\. Compara la red destino.



3\. Determina que el destino es remoto.



4\. Realiza ARP para obtener la MAC del gateway.



5\. Construye la trama.



IP destino:

Destino final.



MAC destino:

Gateway.



6\. El router recibe la trama.



7\. El router consulta la Routing Table.



8\. Selecciona una ruta.



9\. Reenvía el paquete.
