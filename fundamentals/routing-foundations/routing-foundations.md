\# Routing Foundations



\## WHY



Permitir la comunicación entre redes diferentes.



\## WHAT



Una tabla de routing es un mapa que utiliza un router para decidir por dónde enviar un paquete.



\## Conceptos estudiados



\- Routing Table

\- Connected Route

\- Default Route

\- Longest Prefix Match



\## Regla Fundamental



Un router toma decisiones utilizando la IP destino.



\## Longest Prefix Match



Cuando varias rutas coinciden, el router selecciona la más específica.



\## Lessons Learned



La ruta más específica siempre gana.
